# this.l — Assets (first pass)

**Status: spec-compliant _placeholder_ assets.** Everything here is programmer-art
(stick figures, procedural synth audio) generated by `tools/generate_assets.py`.
It exists so the Unity import and core-loop prototype can proceed *now*; bespoke
art and creator-produced audio replace it later. What is already **final** is the
scaffolding the build depends on: dimensions, the 32-color palette, frame counts,
the `actor_action_dir_frame` naming, atlas layout, and the directory structure.

Regenerate any time (deterministic — same output every run):

```bash
pip install Pillow numpy
python3 tools/generate_assets.py            # -> assets/
```

## Layout & import conventions (LOCKED, MANIFEST §0)

- Internal render **640×360**, **1 wu = 24 px**, player/regular height **48 px**,
  Swarmer 24 px. Animate at **12 fps**; ranged frame budgets built at the upper bound.
- Sprites: **PNG**, one **`<actor>_atlas.png`** per actor + individual
  `<actor>_<action>_<frame>.png` frames + `<actor>.json` (clip ranges, timing).
  Unity import: **Sprite (2D), Point filter, no compression, ppu = 24**.
- Each actor JSON carries `"placeholder": true`; the palette JSON does not
  (the palette is real, not placeholder).
